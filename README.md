# 💰 Student Expense Tracker

A simple and user-friendly web application for tracking and analyzing student expenses.

## 🚀 Live Demo

👉 [Open Student Expense Tracker](https://kamleshkumarmandal.github.io/student-expense-tracker/)

## 📌 Project Overview

The Student Expense Tracker helps students keep track of their daily expenses and better understand their spending habits.

The project is built using HTML, CSS, and JavaScript and runs directly in the browser without requiring a backend server.

## ✨ Features

- 📝 Add and manage expenses
- 💰 Track spending
- 📊 Analyze expenses
- 🗂️ Organize expense information
- 🖥️ Simple and responsive user interface
- ⚡ Fast browser-based application
- 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive design
- **JavaScript** – Application logic and expense tracking
- **GitHub Pages** – Deployment and hosting
